# SIGNAL (direction b): fast and minimal

Concept mockups for the menu re-unification, 2026-10-06. Open `index.html` from the file system; the kit showcase is `kit.html` (PNG sheets `out/kit-*.png`). `python build.py` re-renders everything (headless Chromium via Playwright, no network, deterministic).

1. The idea: type does the work. One ground, one accent (volt), hard edges, almost no boxes. One thing is in focus and is drawn large; everything else recedes in size and brightness.
2. Focus language: a list row gets a volt bar and steps from 20 to 56 px (hubs 32 to 96); a cell gets volt corner brackets; a button becomes the one solid volt block; tabs and options get a volt underline. Volt means only focus and what is yours.
3. Controls without boxes: a toggle is a two-word strip with the set word underlined; a choice is a longer strip or a stepper whose arrows exist only in focus; a slider is a hairline, a tick and a numeral; a dialog dims the screen and the question takes it over; a note is a line with a 3 px bar.
4. Four players: tally bars (I, II, III, IIII), a numeral, then a quiet colour. Colour never fills a surface, so there is no rainbow. CPU is hollow bars.
5. Dense screens: the character select keeps the whole roster visible as small cells with the focus huge above it and four port slots below; the remap editor is a list of actions with the focused row enlarged; the Envoy bag keeps a tiny map of everything owned at the top (it doubles as the tab strip) and lists the active group below with the FULL one-line rule for every row and one enlarged focus row.
6. Drive models: real geometry from `melee/pc/scripts/examples/envoy_drives/tools/make_drives.py`, rendered headlessly by `drives.py` (same triangles and atlas colour ramps, flat shaded, fixed light, painter sort, as `gd.kit.model` does). Plain, magic, rare and unique rings. Family of each piece in the mockups is illustrative; names and rule text are the real ones from `APPENDIX-pieces.md`. Brackets like [TIME] mark unknown values. Results numbers and the mod conflict are mock data.
7. Menu structure shown: Solo is flattened (Classic, Adventure, All-Star, Event, Stadium, Training, Lab, Envoy); Online and Mods are promoted to the main menu; Collection and Data share one quiet tail row; Y is a one-press rematch of the last setup.
8. Engine needs beyond flat quads, atlas text and model cells: nothing needs a shader. Needs: atlas text roles at 56, 96 and 160 px (Barlow Condensed), or scaled quads with soft edges as the fallback (Source Sans 3 Black, which is already in the atlas, loses the condensed look); a flat alpha quad for the dialog scrim; hairline quads; the native player's slide and size-step motion (scripts have none). Wide layout: content stays left-anchored and extra width is calm space or a wider detail column (shown on 02, 04, 09).
9. Fonts: Source Sans 3 (SIL OFL, `menu/SourceSans3/`), Hasklug Nerd Font Mono (SIL OFL, `menu/Hasklug/`), and one added family: Barlow Condensed by Jeremy Tribby (SIL OFL 1.1), https://github.com/jpt/barlow, taken from https://github.com/google/fonts/tree/main/ofl/barlowcondensed, files and `OFL.txt` in `fonts/`. The coordinator should add it to `CREDITS.md`.
10. Original work only: glyphs, frames and the stage stand-in are drawn here; disc art is a labelled placeholder; no Nintendo or HAL marks. Credits: Source Sans 3 (Adobe), Hasklug (Nerd Fonts / Source Code Pro derivative), Barlow (Tribby), drive models (this project).
