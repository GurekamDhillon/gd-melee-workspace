# Demo mods implementation plan

**Spec:** `docs/prompts/codex-demo-mods.md` (owner supplied, execution authorized).
**Goal:** A readable feature catalogue, three usable showcases, static/smoke checks and an integrator tour.
**Architecture:** Independent mod folders; a JSON catalogue drives documentation checks and the tour. Existing samples stay in place. The Gauntlet uses contained mission tables and primitive collision so exports are optional.
**Tech:** Lua 5.4, Python 3, JSON, WGSL, Markdown.

## Constraints and rulings

- Work in the deliberately dirty checkouts; no worktree, commits, resets or formatting.
- Lua, Python, JSON, WGSL and Markdown only; no builds or game launch; leave Envoy and engine work alone.
- Registration tables, rather than documentation alone, authorize API calls.
- Source/stub checks do not establish in-game or GPU acceptance.
- Supplied design settles feature scope; execute inline without another design approval.
