# One-system spine implementation plan

> Execute inline with superpowers:executing-plans. The packet forbids commits, game builds and launches; its approval supersedes design/worktree approval gates.

**Goal:** Join existing gameplay contracts in catalogue order, stopping only at an independently usable step boundary.

**Architecture:** Step1 uses scalar string references with a version, scene epoch, actor class, existing engine identity and definition identity. Actor lifetime comes from retail spawn IDs and item serials, not host pointer caches or query-side allocation. Compatibility mappings explicitly distinguish the capability1..12 layout from collision interleaving. Source references are immutable provenance declarations, not mutation permissions. Event metadata is captured when queued, and old callbacks keep their signatures.

**Tech Stack:** PPC game C, native C/Lua5.4, standalone production fixtures and syntax checks.

**Spec:** docs/superpowers/specs/2026-10-04-one-system-catalogue.md section5; docs/prompts/codex-spine-steps-1-5.md.

## Global constraints

Preserve dirty work. No commit/reset/stash/checkout/build.sh/game launch. No held earned-state, technique, crit, tracer or new armour effects. Game/native boundary uses scalar32-bit fields, with references encoded into Lua strings natively. Presentation never becomes simulation authority. Do not introduce new production objects; use includes in existing game/native TUs. Regenerate the Envoy bundle last, once. Public docs contain no machine/disc paths.

## Review focus

Reject malformed, overflowed, obsolete-version and stale references before invoking existing setters. Nana and primary map independently. Respawn/recycle/transformation invalidates old references; replay-restored actors recover their prior references. Item list index is not item identity. Echo identity includes its owner incarnation; reflection changes attribution but not item identity. Source revisions and bound actor lifetime are explicit. Observation queue metadata must be captured before actor destruction and must not dispatch during resimulation.

## Step1: entity/source references and envelope foundation

Create script_spine_refs.h/.inc and gw_script_spine_refs.inc. Game scalar identity reads validate live fighter lists and item serials, existing echo handles and stage object handles. Scene epoch lives in snapshot-covered game BSS and advances at StageEnd without wrapping to a previously valid value. Native APIs entity_ref(selector), entity_resolve(ref), entity_valid(ref), source_ref(kind,key,revision,entity?), source_resolve(ref) expose scalar refs and compatibility IDs. Add entity_call(ref,operation,...) as a narrow bridge to existing capability/hit-rule/echo/zone APIs; validates lifetime and explicit sub-selection first. Existing integer APIs remain unchanged. Add current refs to player/item query rows and Lua port-root exports without changing keys. Add frame/sequence/phase/cause and captured actor refs to a common on_event envelope for the existing queued engine stream, preserving old hooks. Complete cross-stream adapters/tags remain step4.

## Subsequent independently tested boundaries

Step2 follows only after step1 is accepted: descriptor registry and aggregate replay of implemented capabilities/armour/timers with stable output identity and per-effect exactness. Step3 then derives masks/looks/expiry from the current exported named-status authority and proves parity. Step4 completes every observation stream and declared Geno/m-ex/item/echo tags, retaining phase differences. Step5 extracts the shared rule host and installs a gated Classic/Adventure adapter with stage parity. No partial later step is presented as completion.

## Ledger

Ruling: scalar strings preserve full unsigned32-bit IDs across Lua and PPC without native pointer exposure or a mutable host handle allocator. Cost: parsing at script boundaries, not during collision.
Ruling: source references describe provenance and optional actor binding; source revision does not grant ownership or assert a definition was loaded. Geno/roster immutable authored keys are supplied by callers until source-loader integration in step6.
Ruling: complete step1 this pass and stop before step2 if its required independent integration/replay evidence cannot fit safely; the packet explicitly allows this boundary. A common queued event foundation is not step4 completeness.
