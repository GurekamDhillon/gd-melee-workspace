# Geno artist pipeline: gap assessment and workflow (2026-10-08)

Goal: Blender project -> playable `base: "none"` fighter, with the manual steps and trial-and-error removed.
Read from code on 2026-10-08 (`ports/ir/tools/authored_fighter.py`, `plan_parts.py`, `tools/geno/check_art.py`,
`build_courier.sh`, `courier_moves.py`, `ports/vanilla-original/src/*`, game `pc/platform/geno_define_registry.inc`
`gn_plan_parse`).

## Today's path for a new character (manual steps, counted)

1. Write a Blender model script (`build_model.py`, 413 lines, Courier-only) and `common.py` (bone table, hurtboxes, ECB, costumes): 2 files.
2. Write ~5,000 lines of clip code (`clips_*.py`, `anim_lib.py`) and an alias table for 351 engine rows.
3. Export with `export.py` (hardcodes `Courier_Armature`, `Courier`, `courier.glb`), run `make_manifest.py` to emit three JSON files
   (`manifest.json` 351 rows, `skeleton.json`, `hurtboxes.json`). Hand-maintained duplicates of what the glTF already says.
4. `check_art` (reads only the JSON and glb counts; nothing about weights, materials, transforms, clip content).
5. `authored_fighter.py mesh|anim` (hardcodes `courier.glb`, object `Courier`, `GnCourier`, symbol `PlyCourier_Share_ACTION_*`,
   bone names in `COMMON_OF`, bones `trans`/`hips`/`head_top`, "Courier contract" influence limit).
6. `fighterbuild build` per costume with literal symbols `courier_joint courier_matanim` (five commands in `build_courier.sh`).
7. `ui_art.py`, `png2gx` (optional art).
8. Hand-edit `geno.json` (46 attributes, 6 states, 32 subactions), `mod.json`, `retarget.json` (Mario joint index -> bone name table, per-hitbox
   joint/offset/size, delays), run `courier_moves`, copy files into the game checkout's `pc/geno/mods/<key>/files` (shared tree).
9. Set `MELEE_MODS_DIR`, `enabled.txt`, run scene.

Roughly 30 distinct manual steps, about 12 places a name must match by hand (bone names across 4 files, clip names across manifest/glb/rows, symbol names).

## Ranked gaps (by manual steps and mistake opportunities removed)

| rank | gap | what it costs | fix in this lane |
|---|---|---|---|
| 1 | Metadata is hand-maintained JSON generated by Courier-only Python | 3 files, 351 rows, bones, roles, clips duplicated from the glTF; any drift is a silent mismatch | Derive everything from the glb (armature extras, node/clip names, custom props) plus one short `fighter.json`; no manifest/skeleton/hurtboxes files |
| 2 | Converter hardcodes Courier names, paths, bone names | cannot run any other character without editing source | `tools/geno/artist` importer: names, roles, symbols from config; Courier adapter proves no regression (byte-identical outputs) |
| 3 | No authoritative spec; docs contradict code | engine limit vs converter limit vs Courier choice mixed; "converter adds TransN" (it does not), "LHaveN unresolved" fine, stale "none of it started" | `docs/geno-artist-spec.md` with a three-column status per rule and file:line |
| 4 | No generic Blender starter | every artist re-derives axes, rest pose, bone roles, export settings | `blender/make_starter.py`: parametric rig/mesh/sockets/actions/markers + export operator |
| 5 | Clip -> engine row mapping implicit (351 rows, alias statuses) | unmapped rows crash or T-pose in game; no minimum set known | clip table with tiers (prototype / finished), fallback chains, placeholder flags, auto-fill |
| 6 | Validation is manifest-only | weights >2, bad transforms, missing roles found by crash or by eye | glTF-level validator: blocker/warning, names object/bone/vertex/action, states the fix |
| 7 | Moves/attributes hand-built (retarget.json, geno.json) | 32 scripts by hand; sizes tuned for Mario | generator: roles map Striker joints, hitbox size by character scale, attributes from clip reference speeds |
| 8 | Install writes into the shared game checkout; no run loop | stale files, wrong mods dir | `build --install` into an isolated mods dir, ready `MELEE_MODS_DIR`, LAB/scene command |
| 9 | UI art generator is Courier-only | presentation falls back to letters | out of scope; documented (optional, `presentation` keys) |
| 10 | Hit-frame alignment unverifiable without playing | attacks look late | timing table from the move scripts; validator compares action `hit` markers |

## Proposed workflow

```
blender: make_starter (or your own rig on the export skeleton) -> animate -> Geno > Validate / Export+Build
   |  glb (+ armature extras)                 fighter.json (name, key, roles overrides, clip map, root-motion list)
   v
python -m tools.geno.artist build fighter.json --install
   = validate (blockers stop here) -> convert (plan, bank, models via fighterbuild) -> moves/geno.json -> test mod dir
   -> prints the run command (LAB) and whether a restart is needed
```

Decisions taken (recorded, not escalated): the bank/plan format is unchanged; the Courier keeps its own files and passes through a
compatibility adapter; the second character is a sample under `ports/geno-artist-samples/`, never shipped.
