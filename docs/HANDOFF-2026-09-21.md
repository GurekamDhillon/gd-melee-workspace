## Corrections to the previous handoff

1. "Unimplemented opcode XO=183" is **`stwux`**, a standard instruction. It is implemented.
2. There is no "workspace-only" code: the interpreter is `melee/pc/platform/gw_ppc.c`, in this tree.
3. The aurora "GXEnd" diagnosis was a misreading. Aurora parses an immediate draw by the vertex
   count `GXBegin` writes; the `GXEnd` divisibility warning is only a heuristic. The real bug was
   `GXCopyTex(clear)` clearing the **whole** EFB instead of the copy rectangle — fixed; the loading
   screen now covers a match. Do **not** merge `e51d908de` (shim-side primitive close) from
   `agent/native-overlay`.
