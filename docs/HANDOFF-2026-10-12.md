## Traps learned today
- Leads told to stand down must kill only their own PIDs (one pattern-killed shared builds).
- Native writes through a guest pointer must use gw_w32 (the throw region size came back byte-swapped).
- `run.sh --test` runs the native unit suite, not a scene. Use a plain run with MELEE_PAD_SCRIPT for load checks.
- The suite's `settings_env_collisions` trips the default watchdog in worktrees. Use MELEE_WATCHDOG_SECS=600.
