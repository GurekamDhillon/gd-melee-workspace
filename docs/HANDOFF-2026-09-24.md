## Operating reminders

- Build in Git Bash through `tools/port/build.sh` with `GW_MELEE` and a lane-specific
  `GW_BUILD_ROOT`; inspect the log for `error`/`FAIL` even after OK and verify the generated
  `gw_mex_bridge.c` fixpoint. A regenerated uncommitted bridge is normal build output.
- Use `tools/port/run.sh` with a named run and ACE by default. For scripted input,
  `MELEE_INPUT=none`; `gd.press` takes a button string, while sticks/triggers use `gd.input`.
  Script-driven ports must be human, since CPUs ignore `gd.input`. Lua 5.4.7 can syntax-check
  scripts with `luac -p`; `melee/pc/geno/tools/lab_stage_d_check.lua` checks LAB logic offline.
- GD tests visual feel. No verification screenshots. Before each launch check 8 GB free RAM;
  ordinarily one game process per agent; kill only your own checked PID. Keep disc assets
  and extracted character assets out of git. Do not push, publish or merge protected branches
  without GD's explicit instruction; commit messages end in `Co-Authored-By`.
