# GD’s Melee 0.1.8 Linux — public test build

First downloadable Linux package with the portable Qt launcher, disc library,
installed-mod controls, separate per-disc save folders, and native Wayland support.

This release uses the validated Linux port baseline, not the unfinished roguelite
integration. Game source: `d67201cad8b5af87656c23e25716556ad8afa26a` in
`GurekamDhillon/melee`. Launcher and packaging source is this release branch,
based on `8c8f682da006b4e883ff7905a20b758d984a9a08`.

The host must be x86-64 Linux with glibc 2.35 or newer, a 32-bit glibc runtime,
and a matching 32-bit Vulkan driver. The game executable is i686; the Qt launcher
is x86-64. See the packaged README for installation. A user-supplied NTSC-U 1.02
Melee disc image is required. No Nintendo disc data is distributed.

Open `./GD-Melee` after extraction, choose your disc, and press Play. Direct
launch is available through `./launch-melee --iso /path/to/disc.iso`.

Raw Nintendo GameCube adapter support is implemented but physical hardware
validation remains pending. Longer gameplay/audio/custom-content checks and
broader distribution testing remain pending. This release targets offline play;
networking is not certified. The existing Windows release remains available as
v0.1.7; this release supplies Linux artifacts only.

Release checks include source-input hashes, archive contents and runtime hashes,
GLIBC symbol requirements, Qt launcher tests, three-disc engine suites under
Ubuntu 22.04, and native Wayland launcher rendering. Exact evidence and source
metadata accompany the downloadable artifacts. Debug symbols are a separate
optional download.
