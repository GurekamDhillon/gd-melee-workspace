GD's Melee - playing online
============================

WHAT YOU NEED
  - This whole folder. Both of you must use the SAME release (the game refuses a different build).
  - Your own Super Smash Bros. Melee disc image: NTSC 1.02 (USA). Both of you need the same version.
  - A controller: a GameCube controller through an adapter (Wii U mode on Mayflash adapters), or
    any gamepad. The keyboard does not play; it is for hotkeys only.

START THE GAME
  Double-click "GD Melee.exe". The first time, pick your .iso file (it is remembered), then PLAY.
  The first time the game starts it opens SETTINGS > CONTROLS: plug in your controller, press
  some buttons and move the sticks to see that they read, then press B. "How to Play Online"
  on that page has these steps too.
  If Windows says "Windows protected your PC": More info > Run anyway.
  If Windows Firewall asks about melee-pc.exe: tick BOTH Private and Public, then Allow.
  (Without that, your opponent's connection is blocked.)

YOUR NAME
  SETTINGS > ONLINE > Player Name: what your opponent sees in the lobby and before matches.

PLAY SOMEONE YOU KNOW
  One of you:     VERSUS > ONLINE > Host a Room. You get a room code: send it to your opponent
                  (Discord, text...).
  The other one:  VERSUS > ONLINE > Join a Room, then type in that code.
  The rooms use the matchmaking server set in the game's SETTINGS > ONLINE > Server.
  Both of you need the same server. The Qt launcher has no Online tab.

PLAY ANYONE
  VERSUS > ONLINE > Random Opponent: you are matched with whoever else is looking right now.

THE LOBBY
  Blind character picks, starters and counterpicks, 1-2-1 stage strikes and bans, then the game.
  Rematches stay in the room. The host's Stage List (the legal six, or every stage you both have),
  Stocks and Time Limit apply.

WHAT IT FEELS LIKE
  Rollback netcode: your own inputs are instant after the Input Delay (2 frames suits most
  connections). If your opponent's input arrives late, the game quietly corrects itself a few
  frames back. If it stutters, raise Input Delay (SETTINGS > ONLINE, or on the ONLINE screen for
  rooms you host) to 3 or 4.

ENVOY SETS (a private room, two players)
  The host turns on VERSUS > ONLINE > Envoy (SETTINGS > ONLINE > Envoy is the same switch) before
  hosting. The Envoy mod must be installed on both PCs. Each player fights with their own Envoy build
  (a starter drive and a keystone). Between games each player picks a reward: up/down, A takes it,
  B keeps the build; no pick in 30 seconds takes the first offer. The host settles the picks, so the
  two PCs always agree. If the builds are not identical on both PCs the lobby says "Envoy builds
  differ" and the game does not start. If either player leaves, the set ends. Random Opponent never
  plays Envoy. (Only passive drives are online for now; triggered drives come later.)

IF IT DOESN'T CONNECT
  The line at the bottom of the screen says what is happening.
  - Check the firewall question above (both Private and Public).
  - "different disc image": you are not using the same ISO version.
    "different melee-pc.exe build": you are not using the same release.
  - Both of you on the same server? (SETTINGS > ONLINE > Server.)

Netplay protocol 5 (adds the Envoy setting; 4 added the Turbo setting):
  Both PCs need the same current release. A protocol version mismatch means
  update GD's Melee on both PCs; changing the disc will not fix it.
  Matchmaking uses UDP, and optional crash uploads use TCP, normally on
  netplay.gsd.sh:51600. Crash uploads still work from older launchers.
