2. Source code (GPL)
--------------------

The complete corresponding source code for melee-pc.exe is the commit named in version.txt of
https://github.com/GurekamDhillon/melee (branch pc-port); the launcher and the release scripts are
in https://github.com/GurekamDhillon/gd-melee-workspace (tools/release). The third-party libraries
are fetched at the versions pinned in melee/extern/aurora/cmake/AuroraDependencyVersions.cmake.


3. The decompilation
--------------------

The game code is a decompilation of Super Smash Bros. Melee, written by the doldecomp community
without Nintendo's source code. The upstream project publishes no licence, and no rights in the
original game are claimed. This release does not contain, and will never contain, Nintendo's
game data: you need your own copy of the game, dumped from a disc you own.


4. m-ex
-------

Support for m-ex content discs (Akaneia, ACE) is an original reimplementation, in C, of the
behaviour of the m-ex framework (https://github.com/akaneia/m-ex). No m-ex code, assembly or data
is included. Credit for the m-ex design goes to its authors and contributors.
