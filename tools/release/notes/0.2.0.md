> **Public test build.** Please report bugs with what you did, which disc you used, and the crash report from `crashlogs` (or `melee-pc.log` from the game folder).

**Online players:** 0.2.0 uses netplay protocol 5 (0.1.7 used 3). Both players need 0.2.0; a 0.1.x client cannot play a 0.2.0 client and is refused with a clear version message. Until you update, 0.1.x players will not find anyone on the public server.

### New: Envoy

A roguelike run on top of Classic and Adventure. After each stage you pick a **drive**, a piece of loot with rules on it, and you carry four in a bag. Rare **keystones** change the rules of your whole run and come with a drawback. Opponents get stronger the deeper you go, and some of them use technique (wavedashes, L-cancels, perfect shields) against you. Finish a run and the next loop starts again, harder (New Game+). Two players can run it together offline as co-op.

- **It ships in the zip and is on by default** (`mods/envoy` and `mods/envoy_drives`). Start it from SOLO > ENVOY. Turn it off in the launcher's Mods tab.
- **Technique pays.** Crits, afterimages and tracers are earned by playing well (landing techniques, crit hits), not for standing there. **Shock** makes the next hit you take hit harder.
- **Known problems.** The look and the balance are still being tuned, and Envoy has had few full solo runs since its latest changes. A Master Hand that has been burned to zero could leave you falling off the stage for minutes; a guard now puts you back at the cost of a stock. A run started during the opening movie could hang. Both fixes are in but have not been seen working in a game. Some drive names read badly ("Drive of the of Critical Flow"), the text on a few crit drives leaves out their multiplier, and holding the same ordinary rule on two drives counts it once.

### New: online

- **Turbo.** A new match rule: after a connected hit you may cancel into most moves, with limits (no cancelling into the same move, no smash into crouch or jump). The host of a private room turns it on under Online > Turbo, and it is part of the handshake so both players always play the same rules. Random matchmaking always plays without it. Local Versus has the same switch in Settings > Gameplay.
- **Envoy sets (private room, two players).** The host turns Envoy on; each player fights with their own build, and between games the host offers a reward pick. Only the passive drives work online for now. Both players need the Envoy mod installed.
- **Steadier netplay.** The rollback check that detects the two games drifting apart now looks at far more of the game (hitlag, shield, timers, stocks, items), so a real desync is caught on the frame it starts. A bug that stalled a laggy match at the very start is fixed.

### Performance and stability

- **A bad shader can no longer brick the game.** A broken graphics state could crash the game and be saved in the shader cache, so that every later start crashed too. The game now checks the cache at start-up and drops bad entries, and neutralises the bad state in the first place. See below if your game already stopped starting.
- **Grabs.** A crash on a grab with a missing partner is guarded.
- **Stages and CPUs.** Switching stages in a script is reliable, idle CPUs are idle, and Race to the Finish loads correctly.
- **C-stick attacks work in the 1P modes.**
- **Widescreen** setting (`MELEE_WIDESCREEN`).
- Every run now writes a performance record (`perf.json`) next to its log. Heavy fighters can still cost more than the 8 ms a 120 fps game allows; this release does not fix that.

### The launcher

The launcher is now a native program (Qt) in place of the old one, in the new menu style. It keeps your discs, mods and settings choices, and adds a **Diagnostics tab**: when the game stops it explains what it saw, saves a report you can read first, and lets you copy it or open the log folder.

- **Crash report upload is back.** In the Diagnostics tab, "Allow uploading crash reports" is **off by default**. If you turn it on, "Upload last 3 crash logs" sends your three newest crash reports to our server. Nothing is ever sent without that click. Your Windows user name and disc paths are removed from the reports first.

### If the game stopped starting after a crash

Close the game, then delete `pipeline_cache.db` and its two neighbours `pipeline_cache.db-shm` and `pipeline_cache.db-wal` in the game folder (the folder with `melee-pc.exe`; or in `%LOCALAPPDATA%\GDMelee\run` when the game folder was read-only). Start again; the first start is a little slower while the cache is rebuilt. With the new shader-cache guard this should no longer happen.

### LAB and tools

- A CPU virtual controller (script a CPU's pad, retail command scripts, technique macros, "go to" movement) and a combo-tree tool.
- The map editor can do much more: gizmos, multi-select, undo, spawn and camera-bound editing, widescreen.

### For creators: scripting and mods

See `docs/scripting.md` for the full API. New since 0.1.7: skill events (L-cancels to dash-dancing), seeded crits with `on_crit`, shock as a status, stage objectives, models drawn inside a menu rectangle, a `gd.ui` screen system, and a grid-inventory menu component. The Geno fighter engine can now describe a whole fighter (move set, articles, effects, sounds); the zip includes no custom fighters.

### Known issues

- Online play on protocol 5 has been tested on one PC with two game windows, not yet across the internet.
- Online Envoy has only the passive drives; the triggered and echo drives work offline only.
- Turbo's menu and on-screen indicator are new and have had little time on screen.
- Heavy modded fighters are still slower than a 120 fps game wants.
- Linux players on 0.1.8.x use protocol 3 and cannot play with 0.2.0.
- Envoy: see the list above.
