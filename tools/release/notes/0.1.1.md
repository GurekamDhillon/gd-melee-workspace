> **Public test build.** Please report bugs: what you did, which disc, and `melee-pc.log` from the game folder.

### Fixed in 0.1.1
- **GameCube adapter ignored when "Keyboard controls" was ticked.** The launcher box (now "Keyboard controls (controllers still work)") and SETTINGS > Controls > Input Device = Keyboard now put the keyboard on the first free port, and your controllers keep working.
- **Plug the adapter in any time.** The game now picks up a GameCube adapter plugged in after it started, or moved to another USB port, within about a second (like Dolphin). Previously you had to restart.
- **Better support for adapter clones** that number their USB endpoints differently from Nintendo's.

### If your adapter still isn't detected
- Close Dolphin, Slippi and Steam first: only one program can use the adapter at a time.
- If your adapter has a switch (Mayflash), set it to **Wii U** mode.
- Check `melee-pc.log` for lines starting with `gw: gc adapter:` and send them with your report.

Everything from 0.1.0 applies: see its notes for features and known issues.
