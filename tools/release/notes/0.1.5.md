### New in 0.1.5
- **LAB, the frame-data lab (SOLO > LAB).** A game mode of its own for studying any fighter (vanilla, m-ex or Geno): any fighters and CPUs on any stage, KOs respawn, and the clock never runs out. Display modes (hitboxes, hurtboxes, ECB, skeleton and more), a HUD and a full-screen pause menu, long rewind and frame stepping, a savestate library, hot reload of a fighter's files, a state browser for every action state, knockback preview, A/B compare, frame-data export and diff, and a rollback visualiser. It ships as a mod in `mods\geno-lab`. Offline only.
- **The Geno engine.** The port's own layer for fighter content m-ex can't express: new action states, script features, root motion and more, opted into per fighter with a `geno.json`. Fighters without one run exactly as m-ex defines them, and everything Geno adds is deterministic and works online.

### Changed in 0.1.5
- **The keyboard no longer plays: a controller is required.** Play with a GameCube controller through an adapter, or any gamepad. The keyboard is for hotkeys only (F9 controller panel, F10 overlays, ` console), and mods and scripts can add their own (`gd.key`). The launcher's "Keyboard only" box and "Keyboard plays as" port are gone, and the F1 C-stick toggle with them (L+R+START still toggles it in 1P modes).
- **"Connect a controller".** With no controller connected, the game says so on screen until one is plugged in.
- **The mouse works in the menus.** Point and click on the main menu, settings, the online lobby, and the character and stage select; right-click goes back and the wheel scrolls. Matches ignore the mouse. Scripts can read it with `gd.mouse()`.

### Fixed in 0.1.5
- **Items no longer hitch the first time they appear.** Their graphics pipelines are compiled on several threads, prewarmed when the match loads, and the shipped pipeline seed covers them.
- **Crash fixes:** leaving and re-entering the stage select; m-ex costume data (Sonic's and Tails's recolours now show); m-ex fighters whose animation tables or hand models are shorter than the game assumed; level-0 CPUs; scripts reading a fighter the scene had already freed.
- **m-ex fighters:** the results screen shows their names, emblems and stock icons, and up to 94 m-ex fighters can be loaded (was 31).
- **Bit-exact with the console.** Matrix maths now rounds exactly like the GameCube, and real console replays (Slippi `.slp`) play back matching frame by frame.

Everything from 0.1.4 applies: see its notes for the other changes and known issues.
