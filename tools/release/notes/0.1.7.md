**Online players:** 0.1.7 uses netplay protocol 3. Both players need 0.1.7; an older client is refused with a clear version message.

### Performance

- **High refresh rates.** The renderer has far more headroom. The game can run uncapped or at 120/144 Hz, with smooth frame interpolation between game frames. Several interpolation glitches are fixed (stretched models and "spike ball" shapes between frames, flickering overlay panels at 120 fps).
- **Faster game logic.** Matrix math no longer goes through a slow software path, and heavy custom fighters cost much less per frame.
- **Faster boot and loading.** The first frame appears sooner, controller enumeration no longer stalls start-up, and the loading screen shows everywhere a match or mode loads.
- **Cheaper rollback.** Rollback saves are 56-60% cheaper, memory snapshots are shared between saves, and a deep-rollback crash with custom fighters is fixed.
- **No more crash on heavy scenes.** When a frame has more to draw than the renderer's per-frame buffer holds, the buffer is now large enough (and an overflow drops draws instead of closing the game).

### LAB and tools

- **Performance overlay.** Press F4 in LAB for frame times, FPS, draw calls and live effects. Show FPS in the settings now uses the menu style.
- **New menu frames.** Every menu panel uses new art and can be drawn at any size and shape.
- **Debug flight.** Fly and teleport freely in any offline mode, not just LAB. The fighter now hovers in place instead of falling.

### 1P modes

- **Classic step 7** no longer crashes during its intro.
- **The Master Hand fight** ends properly: the clear and results screens play after the KO.
- **Snag the Trophies, Race to the Finish and Classic step 1** load correctly.
- More memory for fighter files, so large modded fighters load in 1P modes.

### Versus

- Short time limits (under a minute) and stock counts are respected.

### For creators: scripting and mods

Lua scripts and mods can do much more. See `docs/scripting.md` for the full API.

- **Camera:** script the camera for cinematics, then hand it back.
- **Stages:** add platforms, walls and Target Test targets to any stage at runtime, move or remove them, and read the stage's bounds.
- **Custom 3D models:** load models from a mod and place, move, mirror and remove them on any stage, with their own collision and glass. They are batched for performance, kept in savestates and freed when the match ends.
- **Map editor** (an example script mod): build layouts from a modular kit with a fly cursor, then save and reload them.
- **Enemies:** spawn Adventure enemies (Goomba, Koopa, ReDead) on any stage.
- **Gameplay:** apply real hits with `gd.hit` and set damage directly. Scripted inputs now count game frames, so they stay correct while paused or frame-stepping.
- **Boss fights:** a hook when a boss is defeated, with an optional hold for extra content before the match ends. An example adds a target bonus after Master Hand.
- **Geno fighter engine (v5.5):** projectiles and articles, on-hit hooks, counters, stick-aimed moves, per-hitbox extra hitstun, hitlag and damage flags, a native effects runtime with bloom, and a matrix-palette path that makes detailed custom fighters much cheaper to draw.
- **Mod requirements:** a mod can declare the engine features it needs; a build without them won't mount it.
