> **Hotfix for 0.2.0.** Same game as 0.2.0 with one fix. Windows and Linux 0.2.1 play each other; they do not play 0.2.0 (update both sides).

### Fixed

- **Data > Snapshots froze the game.** Opening the Snapshots screen from the main menu's Data menu could hang the game for good. The menu now saves pending memory card changes before it opens the screen, as the original game does, so the card scan no longer collides with that save.

### Known issues

- There is no fullscreen option yet. It is coming in the next update (F11 or Alt+Enter, and a launcher setting).
- On some Linux laptops the game runs below 60 fps, which also slows an online match with a Windows player to that speed. Being worked on.
- Everything listed under "Known issues" in 0.2.0 still applies.
