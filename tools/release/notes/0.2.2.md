> **Public test build.** Please report bugs with what you did, which disc you used, and the crash report from `crashlogs` (or `melee-pc.log` from the game folder). Windows and Linux 0.2.2 play each other; they do not play 0.2.1 or earlier (update both sides).

### New

- **Mod browser (SSBM Nucleus).** Browse and search mods without leaving the game, with thumbnails and filters. Pick mods into an install queue (it survives a restart) and the game downloads and installs zip mods for you. Mods from SSBM Nucleus - https://ssbmnucleus.net. Built with permission from sc00p.
- **Everything is unlocked by default.** Every fighter and stage is available from the start. Turn it off in Settings > Gameplay.
- **Fullscreen.** F11 or Alt+Enter, and a Video setting.
- **255 costumes per fighter.** Skins are no longer limited to the original palette slots.

### Online

- **Envoy sets resume after a disconnect**, and you can abandon a set. A mid-match freeze is fixed. A tied game is replayed instead of going to sudden death.
- **Stricter disc check.** A player on a different disc image is refused online instead of desyncing.
- **Windows-vs-Linux checksum false alarm fixed.** Matches no longer end with a bogus mismatch.

### Linux

- Rollback snapshots are much faster, and the crashes with Turbo are fixed.
- Envoy drive items, the crit shader and mod surface shaders now work on Linux.

### Fixed

- The shader cache no longer fills the drive.
- Data > Snapshots no longer freezes the game (also in 0.2.1).

### Known issues

- New skins appear after a restart.
- Everything listed under "Known issues" in 0.2.0 and 0.2.1 still applies, except fullscreen, which is now here.
