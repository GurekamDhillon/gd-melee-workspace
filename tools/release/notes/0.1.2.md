> **Public test build.** Please report bugs: what you did, which disc, and the crash report from the `crashlogs` folder (or `melee-pc.log` from the game folder).

### Fixed in 0.1.2
- **Local VS matches closed while loading ("memp_kouho").** Starting a match from the character and stage select could run out of memory and close, with any fighter, mod or not. Fixed. This was also the "several mod fighters run out of memory" known issue from 0.1.0: four mod fighters on a mod stage now load fine. Online matches weren't affected.

### Controls
- **Keyboard and controller together, by default.** The keyboard and a controller share port 1, and whichever you touched last plays. A controller takes over once you actually press a button or move a stick. To make the keyboard a separate player, set "Keyboard plays as" in the launcher.
- **Arrow keys are now the C-stick**; the D-pad moved to T/F/G/H. F1 still toggles the C-stick.
- **The GameCube adapter is released when you alt-tab out**, so Dolphin or Slippi can use it, and picked up again when you come back (calibration kept). It stays claimed during online matches. Turn this off in the launcher's Diagnostics tab.
- "Keyboard only" in the launcher replaces the old "Keyboard controls" box.

### Crash reports and logs
- **Shorter logs.** The game log is about 90 times smaller, so it's easier to send.
- **Crash reports.** A crash now writes a short report (`crashlogs\crash-<time>.log`) next to the full log, with your Windows user name removed. Closing the window with X never counts as a crash.
- **Diagnostics tab in the launcher** with the logging options we might ask you to turn on, and buttons to open the log folder and copy the latest crash report.
- **Optional crash report upload.** Off by default. If you turn it on, "Upload last 3 crash logs" sends your three newest crash reports to our server. Nothing is ever sent automatically.

- Everything else from the 0.1.0 notes, except the out-of-memory issue fixed above.
