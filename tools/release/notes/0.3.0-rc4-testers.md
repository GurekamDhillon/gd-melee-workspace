# 0.3.0-rc4 test instructions (DRAFT, not sent)

For the owner to paste into a private gist and send to testers once he says go. Nothing here is published.
Fill in the two links where marked. The build is a release candidate: it may still have bugs.

## What this is

GD's Melee 0.3.0 release candidate 4. Big changes since 0.2.2: netplay protocol 7 (**0.2.x and rc3 cannot
play rc4 online**; everyone in a match must be on 0.3.0-rc4), UCF 0.84 on by default offline, six fighters in a
match, the in-game Nucleus mod browser (stage skins, custom stages, mod fighters opt-in, mod sync by Nucleus
post id), a Melee-style character select (coins and free hands), a per-player tap jump option and per-fighter Controls, a launcher update notice, `.gdlp` replays, template fighters, a fix for the second-match crash, and Workbench/launcher updates.
Full notes: tools/release/notes/0.3.0.md.

You need your own Melee NTSC-U 1.02 `.iso`. The download contains no game data.

## Windows

1. Download `GDMelee-0.3.0-rc4-win64.zip` from <LINK>. Check it: `certutil -hashfile GDMelee-0.3.0-rc4-win64.zip SHA256`
   must print the hash given with the link (<HASH>).
2. Unzip to a normal folder (not Program Files). Run `GD Melee.exe`. Point it at your `.iso` the first time.
3. Check, and write down what you see:
   - Play a 1v1 offline match, then a second match on a different stage (this used to crash).
   - Settings: UCF is on by default; turn it off and on again.
   - Character select (VS): pick up a coin and a hand, move the hand over a fighter, drop the coin; check the hand and coin look like Melee's. Turn tap jump on for one player and off for the other (Controls); check each behaves.
   - Open the mod browser (main menu: Right, Up, Up, A, then Z). Install one stage skin. Restart the game; check it appears.
   - LAB: open it, record a few seconds of inputs, play them back.
   - Online with a friend (both on 0.3.0-rc4): create a room, join by code, play one game. Note ping and any desync message.
4. If anything breaks: send `melee-pc.log` (game folder) and the newest file in `crashlogs`, plus what you did and
   which disc you used.

## Linux

(The Linux tarball is built separately: `GDMelee-0.3.0-rc4-linux-x86_64.tar.xz`, <LINK>, hash <HASH>.)

1. `sha256sum GDMelee-0.3.0-rc4-linux-x86_64.tar.xz` must match. `tar xf` it into a normal folder.
2. Run the launcher (`./gd-melee-launcher`) or the game script it ships; point it at your `.iso` the first time.
3. Same checklist as Windows. Also note: frame rate in a match (is it a steady 60?), your GPU/driver, and your
   desktop (X11 or Wayland). If the game does not start, run `./gd-melee-diagnose.sh` and send its output.
4. Online against a Windows tester (both on 0.3.0-rc4): one game, then say whether the checksums agreed (no mismatch message).

## What to send back

Per tester: OS, GPU, which items above worked, and logs for anything that did not. Screenshots of the game
are welcome as long as they are of your own play; do not send disc files.
