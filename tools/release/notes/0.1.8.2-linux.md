A second repack of the 0.1.8 Linux test build. It replaces 0.1.8.1, which fixed only part of the problem.

### What was wrong

On a distribution with a current Mesa the game stopped before its window opened with **"No supported adapters"**. The package carried its own 32-bit copies of libraries that the system's graphics driver also uses, and they were older than the driver needs. 0.1.8.1 removed the C++ runtime; the Wayland library had the same fault: Mesa 26.2's Radeon Vulkan driver needs `wl_display_create_queue_with_name`, `wl_display_dispatch_queue_timeout` and `wl_fixes_interface`, which the bundled `libwayland-client` does not have, so the driver could not load inside the game.

### What changed

The game no longer carries anything the graphics driver links against: Wayland, X11 and XCB, zlib, zstd, libffi, and the C++ runtime (`libstdc++`, `libgcc_s`). It uses the system's 32-bit copies, which match the driver. Nothing else changed: the same game, launcher and netplay version as 0.1.8.

### Download and launch

Download **GDMelee-0.1.8.2-linux-x86_64.tar.xz**, extract it to a new folder, and run `./GD-Melee`. Saves, settings and mods from 0.1.8 are kept.

A system with a working 32-bit Vulkan driver normally has these 32-bit packages already:

| distribution | packages |
|---|---|
| Arch, CachyOS, Manjaro, EndeavourOS | `lib32-gcc-libs lib32-wayland lib32-libx11 lib32-libxcb lib32-zlib lib32-zstd lib32-libffi` |
| Debian, Ubuntu, Mint (`:i386`) | `libstdc++6 libwayland-client0 libwayland-cursor0 libwayland-egl1 libx11-6 libx11-xcb1 libxcb1 zlib1g libzstd1 libffi8` |
| Fedora (`.i686`) | `libstdc++ libwayland-client libwayland-cursor libwayland-egl libX11 libX11-xcb libxcb zlib-ng-compat libzstd libffi` |

### How it was checked

The Wayland fault was found by comparing the symbols Mesa 26.2.4's 32-bit Radeon driver imports against the bundled libraries. The package's checksums verify and the game resolves every library on a machine without the bundled copies. It has **not been run on a graphics card**. If it still does not start, run `VK_LOADER_DEBUG=error,warn,driver ./GD-Melee`, press Play, and send the newest game log.
