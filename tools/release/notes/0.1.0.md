> **Public test build.** This is an early preview for testing. Expect bugs, and please report them (what you did, which disc, and `melee-pc.log` from the game folder).

### What you can do
- **Play online** with a friend using a short room code, or press **Random Opponent** to be paired with anyone who's searching. Rollback netcode; a competitive lobby handles blind character picks, stage strikes and bans, ready-up, and rematches in the same room.
- **Use mods, including online.** Mod discs (ACE, Akaneia) work, and so do loose mods in the `mods` folder, toggled in the launcher. Online, you can pick any fighter or stage both players have; the rest are greyed out.
- **Browse and install mods** from the launcher's Mods tab. Downloads are verified before they're installed and never run.
- **New character and stage select screens** that list every fighter and stage your disc and mods provide, with pages for big rosters.
- **Graphics:** render at higher resolutions (`MELEE_RENDER_SCALE`), turn vsync off, and try an experimental uncapped frame rate.
- **Lower input latency:** controller input reaches the screen in about 13 ms, steadily.
- **Scripting and a console** (press the backtick key in game) for modders and practice. Try `load builtin:tm_lite` for save/load positions on F5–F8.
- **A Settings screen** (main menu > SETTINGS): video, audio (volume, music/effects mix), controls, your online player name and server, mods, and gameplay options. Changes apply right away and are saved.
- **Everything unlocked** from the start, without a save file (launcher checkbox, always on online).

### Known issues
- Training-mode features like UnclePunch's Training Mode (lab, CPU options, hitbox display) aren't here yet. `tm_lite` is a small stand-in.
- TM-CE and 20XX discs boot, but their special features don't work.
- Fighter and stage mods from different packs (for example ACE fighters with Akaneia stages) can't be mixed yet.
- The uncapped frame rate is experimental: the picture trails the game by one frame, and some objects may pop during fast camera moves.
- Teams mode and 4-player local matches on the new character select have had little testing.
- The launcher isn't code-signed, so Windows SmartScreen warns on first run.
